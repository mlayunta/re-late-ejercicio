# Re-Late Salud y Ejercicio 🫀

Aplicación web progresiva (PWA) enfocada en la rehabilitación y control cardiovascular para adultos mayores.

## 🚀 Características
- **Pestaña Ejercicio:** Catálogo guiado para Aire Libre, Gimnasio y Casa.
- **Control de Salud:** Registro de pulso y tensión pre/post entrenamiento con gráficos dinámicos.
- **Progreso:** Visualización de metas y exportación de informes.
- **Modo Offline:** Funciona instalada en el móvil sin necesidad de conexión constante.
